# 한입습관

오늘의 급식 메뉴를 직접 입력하고, 식사 결과를 간단히 기록하는 웹 앱입니다.

## 실행

Node.js 22 이상에서 이 폴더를 열고 실행합니다. 별도 패키지 설치는 필요하지 않습니다.

```sh
npm start
```

브라우저에서 http://127.0.0.1:8001 에 접속합니다. 정적 파일만으로 동작하므로 GitHub Pages에서도 사용할 수 있습니다.

## 사용

1. 급식 메뉴를 쉼표 또는 줄바꿈으로 구분해 입력하고 저장합니다. 날짜별로 저장됩니다.
2. 식사 후 ‘다 먹었어요’ 또는 ‘조금 남겼어요’를 선택합니다.
3. 남겼을 때만 메뉴와 이유를 입력하고 기록을 저장합니다. 같은 날 다시 저장하면 그날 기록이 수정됩니다.
4. 리포트에서 요일별 클린 식판 횟수, 메뉴별 남긴 횟수와 이유를 확인합니다.
5. 요약과 리포트에서 누적 예상 잔반 감소량·탄소 절감량, 클린 식판 횟수·포인트, 단계별 챌린지를 확인합니다. 기존 1·3·7회 배지도 유지됩니다.

예상 절감량은 앱 내 예시 가정(클린 식판 1회당 잔반 0.1kg, 잔반 1kg당 2.5kg CO2e)으로 환산합니다. 실제 측정값이나 검증된 개인별 절감량이 아니며 음식 종류·배식량·처리 방식에 따라 달라집니다. 기록을 수정하거나 초기화하면 수치와 배지도 다시 계산됩니다. 연속 달성은 주말을 포함한 달력 날짜 기준이며, 어제 또는 오늘까지 이어진 연속 기록을 현재 일수로 표시합니다.

사진 첨부는 선택사항이며 미리보기만 제공합니다. 사진은 저장하거나 외부로 전송하지 않습니다. API 키나 외부 서비스 연결은 필요하지 않습니다.

기록과 메뉴는 이 브라우저에 저장됩니다. 같은 브라우저와 같은 주소로 접속해야 기존 기록이 보입니다. 이전 버전의 무게 기반 기록은 남김 여부로 변환해서 읽으며, 기존 기록과 포인트를 이어서 사용할 수 있습니다.
